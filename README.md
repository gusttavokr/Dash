# 🚀 Dash Framework

Processo ágil leve baseado em Scrum/Kanban, otimizado para desenvolvimento de jogos.

## 📋 Sobre

Dash é um processo ágil que combina as melhores práticas do Scrum e Kanban, criando um fluxo de trabalho iterativo e eficiente. Projetado especialmente para equipes de desenvolvimento de jogos.

## ✨ Características

- **Sprints de 1-2 semanas** com foco em feedback contínuo
- **5 fases bem definidas**: Concepção, Pré-Produção, Produção, Feedback, Pós-Produção
- **3 papéis claros**: Product Owner, Scrum Master, Developer/Designer
- **Práticas ágeis integradas**: Scrum, Kanban, Pair Programming, CI/CD, TDD/BDD
- **Ciclo iterativo** que se repete até a última sprint oficial

## 🎯 Ciclo Principal

```
Concepção → Pré-Produção → Produção → Feedback
      ↑                                    ↓
      └────────────── (Loop até última sprint)
                           ↓
                    Pós-Produção
```

## 🚀 Como Visualizar

Abra o arquivo `index.html` em seu navegador para visualizar a documentação completa com:
- Diagrama de atividades interativo
- Descrição detalhada de todas as fases
- Tabela de papéis e responsabilidades
- Lista de práticas ágeis aplicadas
